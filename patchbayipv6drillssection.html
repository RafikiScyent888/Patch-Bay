    Compression, in two rules

    1. Drop leading zeros inside each group — 0db8 → db8, 0000 → 0. Never trailing zeros: 1200 stays 1200.
    2. Replace one run of all-zero groups with :: — once per address, only once. Two separate runs? :: goes on the longer one; on a tie, the leftmost. A run of a single zero group stays written as 0.

    What makes an address invalid

    More than one :: · more than eight groups · fewer than eight groups with no :: to fill the gap · a group longer than four hex digits · any character outside 0-9 and a-f.

    Address types

    BlockTypeThe tell
    2000::/3Global unicastFirst hex digit is 2 or 3. Routable — the IPv6 "public IP."
    fe80::/10Link-localStarts fe80. On every interface, always. Never routed off the segment.
    fc00::/7Unique localIn practice starts fd. The RFC 1918 equivalent.
    ff00::/8MulticastStarts ff. Replaces broadcast — IPv6 has none.
    ::1LoopbackThe 127.0.0.1 equivalent.

    Prefixes and subnets

    The prefix length counts bits from the left, and every four hex digits is 16 bits — so a /32 is the first two groups, /48 the first three, /64 the first four. To find the prefix: keep those groups, zero everything after.
    Subnets available going from /a to /b: 2^(b−a). Addresses inside a /n: 2^(128−n).
    You do not subtract two. IPv6 has no broadcast address, so the all-ones address at the top of a subnet is a usable host address — unlike IPv4.

    EUI-64, in three moves

    1. Split the MAC 24 | 24 — three bytes of OUI, three of device ID.
    2. Insert ff:fe in the gap → 24 + 16 + 24 = 64 bits.
    3. Flip the 7th bit of the first byte — the U/L bit. Invert it, don't set it.
    Then regroup into 16-bit blocks, and prepend fe80:: for the link-local form.

    The flip, as a lookup — use only after doing it longhand

    0↔21↔34↔65↔7 8↔A9↔BC↔ED↔F

    The flip only ever changes the second hex digit of the first byte.

    Solicited-node multicast

    Every unicast address has one. Take ff02::1:ff00:0/104 and append the host's last 24 bits — so …:fe28:9c5a becomes ff02::1:ff28:9c5a. Neighbor Discovery uses it instead of an ARP broadcast.
